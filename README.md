# Hi there 👋

**Senior Backend Engineer · .NET / C#** · 5+ years building distributed backend systems: library management platform, industrial IoT, SCADA.

- 🏗️ Microservices with **DDD, Clean Architecture and CQRS** on .NET 10, PostgreSQL and RabbitMQ
- 🔐 Designed platform-wide **RBAC + scoped authorization** (claims → functions → permission groups, scoped to an org-structure node)
- ⚡ Cut reader search from **40–50 s to under 200 ms** on 2M+ records with PostgreSQL full-text search and a transactional outbox
- 📦 Built resumable migration pipelines for multi-GB legacy exports: 3–4M records per run, constant memory
- 🔭 Introduced **OpenTelemetry tracing + Graylog** across 7 services; an issue that survived three debugging attempts was then traced in about 7 minutes
- 🤖 Daily driver: **Claude Code** with MCP servers and custom skills
- ⚡ Fun fact: I'm really obsessed with capybara memes
